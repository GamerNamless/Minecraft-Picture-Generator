# Minecraft Picture Generator

<a name="english"></a>
## English

A lightweight, browser-based utility designed to split any image into Minecraft player skin fragments (8x8 pixel heads)[cite: 1]. It allows you to build custom map arts and murals in Minecraft using decorative player heads without installing external software or mods[cite: 1].

### Key Features
* **Zero Installation:** Runs entirely client-side in any modern browser via vanilla JavaScript and HTML5 Canvas[cite: 1].
* **Flexible Sizing:** Configure canvas size by player heads (1 block = 8x8 px) or by raw pixel values (with an 8 px step)[cite: 1].
* **Interactive Mapping:** Pick target skin coordinates directly by clicking on the interactive skin preview (Left Click for base layer, Right Click for second/overlay layer)[cite: 1].
* **Numbered Assembly Map:** Generates a numbered layout map (`_map.png`) showing exactly where each numbered skin block belongs[cite: 1].
* **Flexible Export:** Download all generated skin files plus the helper map as a single `.zip` archive or directly in batch[cite: 1].
* **Bilingual UI:** Native interface support for English and Russian[cite: 1].

### How to Use
1. Open `Minecraft Picture Generator.html` in your web browser[cite: 1].
2. Click **Launch Program**[cite: 1].
3. **Canvas Setup:**
   * Choose dimension mode: in heads or in pixels[cite: 1].
   * Set width and height, upload your target picture, and click **Load and Downscale Image**[cite: 1].
4. **Skin & Layer Placement:**
   * Upload a standard Minecraft skin template (64x64 or 64x32)[cite: 1].
   * Left-click to place the primary 8x8 fragment[cite: 1].
   * Optionally check "Include 2nd layer" and right-click to place the secondary fragment (hat/helmet)[cite: 1].
5. **Export:**
   * Enter an archive name, choose between a single `.zip` file or batch download, and click **DOWNLOAD**[cite: 1].
   * Follow the generated assembly map to place player heads in Minecraft[cite: 1].

<a name="russian"></a>
## Russian

Удобный веб-инструмент для нарезки любых картинок на фрагменты скинов Minecraft (8x8 пикселей)[cite: 1]. Позволяет собирать большие картины и настенные арты из голов игроков прямо в игре без модов и сложного софта[cite: 1].

### Основные возможности
* **Работает прямо в браузере:** Не требует установки сторонних программ, все вычисления происходят на стороне клиента[cite: 1].
* **Настройка полотна:** Можно задавать размер картины как в головах (1 блок = 8 пикселей), так и в пикселях с шагом в 8px[cite: 1].
* **Интерактивная разметка:** Выбор места вставки на скине прямо кликом по холсту (ЛКМ — основной слой, ПКМ — второй слой / шлем)[cite: 1].
* **Карта-шпаргалка:** Автоматически генерирует схему сборки с номерами (`_карта.png`), чтобы не запутаться при установке голов в мире[cite: 1].
* **Удобный экспорт:** Сохранение результата одним ZIP-архивом или массовой загрузкой отдельных файлов[cite: 1].
* **Поддержка двух языков:** Полный перевод интерфейса на русский и английский[cite: 1].

### Инструкция по использованию
1. Откройте файл `Minecraft Picture Generator.html` в любом браузере[cite: 1].
2. Нажмите **Запустить программу**[cite: 1].
3. **Настройка полотна:**
   * Выберите режим измерения (в головах или пикселях)[cite: 1].
   * Укажите ширину и высоту, выберите картинку и нажмите **Загрузить и сжать картину**[cite: 1].
4. **Выбор скина и позиционирование:**
   * Загрузите шаблон скина (64x64 или 64x32)[cite: 1].
   * ЛКМ укажите область для основного слоя (8x8)[cite: 1].
   * При необходимости включите второй слой и ПКМ укажите область шлема[cite: 1].
5. **Экспорт:**
   * Укажите имя архива, выберите вариант сохранения (ZIP или отдельные файлы) и нажмите **СКАЧАТЬ**[cite: 1].
   * Используйте сохраненную карту-шпаргалку для пошаговой расстановки голов на сервере или в одиночной игре[cite: 1].
